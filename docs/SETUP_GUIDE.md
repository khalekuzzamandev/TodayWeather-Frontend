# Setup guide

## Windows PowerShell

```powershell
cd D:\MY-PROJECT\TodayWeather\TodayWeather-Frontend
npm install
npm run dev
```

Then visit http://localhost:3000.

## Git Bash

```bash
cd /d/MY-PROJECT/TodayWeather/TodayWeather-Frontend
npm install
npm run dev
```

## Common commands

```bash
npm run lint
npm run build
```

## Troubleshooting

- If a port is already in use, stop the old dev server or pass another port.
- If packages are not installed, run `npm install` again.
- If the browser blocks location access, allow geolocation permission or search for a city manually.
